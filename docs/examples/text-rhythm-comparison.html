TEXT-001: semantic text rhythm comparison

Static, synthetic, non-normative design evidence. Space can signal a related thought transition; a native thematic break means more than a large margin. Decorative symbols never establish meaning by themselves.

The example-only profile/scheme attributes and CSS values are not Chroma, Lamina or Venation contracts. There is no JavaScript, remote dependency, runtime inference or dynamic adaptation.

Evidence boundaries

Compare at 320, 375, 768 and 1280 CSS px, both illustrated profiles and schemes; enlarge text to 200%, apply user text-spacing overrides, enable forced colors, print and disable stylesheets. These are review instructions, not claims of tested behavior.

In the ornament specimen the hr remains the one semantic thematic break; the asterism is explicitly hidden from accessibility APIs. Forced-colors and print CSS reveal the native line instead of depending on the glyph; without styles, the native rule also remains visible. These browser probes do not replace real screen-reader or print-output verification.

The build-time suggestion data accompanying this example is synthetic, reviewable evidence. It is not run or consumed in readers, and it does not claim that AI selected a semantically correct boundary.
