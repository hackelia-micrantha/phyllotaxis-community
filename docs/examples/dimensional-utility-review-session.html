For study owners only: interpretation and ethics

The scanning cases correspond to flat (F0-like), bounded (B1-like) and intentionally stacked (B2-like) presentations. The affordance cases compare differentiated and equal-elevation B3-like patterns. Options are shuffled locally when JavaScript runs, and exported response data records the displayed order. The materials are not canonical fixture re-renders, not a representative usability study, and not an accessibility conformance audit. Do not count an assistant-generated response as independent human evidence. Keep reviewer identities out of public GitHub issues.
