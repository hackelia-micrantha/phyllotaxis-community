# Design examples

Files in this directory are evidence-bearing reference compositions, not package artifacts or stable component APIs.

- [Utility reference](utility-reference.html) — synthetic no-JavaScript composition showing compact introduction, flat low-chroma surface rhythm, border-sharing information grids, explicit state labels, link-first actions, and one bounded interactive hover example with reduced-motion handling.

Reference CSS may use local example-only values to demonstrate a design property. Those values do not become Chroma contract roles unless separately accepted through the design-decision process.
