# Design examples

Files in this directory are evidence-bearing reference compositions, not package artifacts or stable component APIs.

- [Utility reference](utility-reference.html) — synthetic no-JavaScript composition showing compact introduction, flat low-chroma surface rhythm, border-sharing information grids, explicit state labels, link-first actions, and one bounded interactive hover example with reduced-motion handling.
- [Dimensional Utility comparison](dimensional-utility-reference.html) — synthetic, **non-normative** RFC-0008 comparison of flat, tinted, raised, gloss, inset, and accent-edge presentations. Browser evidence is preliminary; [ADR-0008](../decisions/ADR-0008-dimensional-utility-advisory-guidance.md) accepts only advisory review guidance, not these example treatments as normative requirements or stable APIs.

- [SPACE-001 spacing comparison](spatial-rhythm-comparison.html) — non-normative, static three-policy specimen of section/group/inset/prose/table spacing. The [review plan](../architecture/spatial-rhythm-review-plan.md) separates static fixture integrity from unverified browser and usability observations.

- [TEXT-001 text-rhythm comparison](text-rhythm-comparison.html) — non-normative, no-JavaScript comparison of continuity, transitions, thematic breaks and a decorative asterism under Utility/Editorial and light/dark. [Synthetic static suggestion cases](text-rhythm-suggestions.json) demonstrate accepted/pending/stale/invalid document anchors; see the [review plan](../architecture/text-rhythm-review-plan.md) for evidence still needed.

Reference CSS may use local example-only values to demonstrate a design property. Those values do not become Chroma contract roles unless separately accepted through the design-decision process.

The pending [GitHub Pages reference gallery](../../site/README.md) collects these public fixtures. It is **not** a package-backed component demo, and its live publication status must be verified separately.
