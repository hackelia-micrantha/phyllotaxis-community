# Independent Utility review — participant instructions

This ZIP is a **local, non-commercial, voluntary review exercise** for the public Phyllotaxis design-system project. It is not a certification, a released application, or an endorsement request.

## Open the session

1. Unzip the archive without moving individual files out of their folders.
2. Open `docs/examples/dimensional-utility-review-session.html` in a browser.
3. Complete both exercises before opening the page's **study-owner interpretation** section or the linked source examples.
4. Compare the options and write what you actually notice: status clarity, visual distractions, and which areas you expect to be interactive. There is no correct preference.
5. Use **Download local JSON review** if you want a copy of your responses. Review the JSON before sharing it voluntarily with the project owner. Do not include your name, contact details, passwords, confidential information, or identifying details.

The review form makes **no network request and performs no automatic upload**. The JSON stays on your device unless you choose to send it. No cookies, analytics or persistent browser storage are used. JavaScript changes display order locally; the exported JSON records that order. Without JavaScript, use `docs/architecture/dimensional-utility-human-review-worksheet.md` and note that the option order was not randomized.

Record the **source commit supplied alongside the download** in the form's commit field. A provenance file accompanying the GitHub Actions artifact identifies the checked-out revision; if it is missing, leave the field blank rather than inventing a value.

You may stop at any time and may choose not to share responses. If a design does not work with your input or accessibility settings, describe what you experienced and mark untested conditions clearly.

## Review limitations

The exercise uses matched text and semantics across visual treatments, which are simplified versions of Phyllotaxis's canonical design fixtures. One person's preference is not a representative user study. A successful browser check or this packet's existence does not establish WCAG conformance, user approval, or a new stable design-system API.

The accepted Utility profile stays **flat-first**; its optional dimensional styling guidance is advisory only.
